O personagem tem fundo branco (sem transparência). Escolha como exibir dentro do círculo:

1Círculo com fundo branco

Personagem exibido com fundo branco dentro do círculo. Cria contraste limpo com o fundo escuro — visual de "spotlight" profissional.

2Círculo com fundo escuro + mix-blend

CSS mix-blend-mode: multiply remove o fundo branco visualmente. O personagem aparece "solto" no azul escuro, mais integrado.

3Personagem sem círculo — tamanho maior

Personagem exibido em tamanho maior sem o frame circular — corpo inteiro visível, estilo mais editorial. Requer remoção do fundo branco via CSS.
